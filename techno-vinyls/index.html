Techno Vinyls is a focused Discogs browser for discovering techno releases on vinyl. Search by artist, scan release details, and follow through to Discogs for the listing.

Prototype status. The current app searches Discogs, filters for vinyl releases tagged only as Techno, supports artist search and paginated results, and shows release details with Discogs' current lowest listed price when available. Built for crate-digging

Keep the catalogue easy to scan: useful release metadata first, artwork when Discogs provides it, and price context that points back to the source.

Filter for straight techno

Browse vinyl releases whose style tags are exclusively Techno, rather than mixed-style crossover results.

Use available release artwork

Show Discogs artwork when a release has it, with a restrained fallback when artwork is missing.

Show Discogs' lowest price

Display the current lowest listed price returned by Discogs, or say when no price is available. The listing can change; Discogs is the source.

Early prototype, not a finished marketplace. Techno Vinyls helps you discover and compare releases; Discogs remains the source for current listings and availability.
